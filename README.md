
# Stablecoin Treasury Dashboard

Stablecoin Treasury Dashboard is a lightweight TypeScript application for monitoring company treasury balances held in USDC.

## Features

- USDC balance overview
- Treasury statistics
- Multi-wallet support
- Console dashboard
- Chart-ready datasets
- CSV export
- Daily treasury reports

## Project Structure

```
src/
 ├── config
 ├── dashboard
 ├── data
 ├── models
 ├── services
 └── utils
```

## Build

```bash
npm install
npm run build
npm start
```
